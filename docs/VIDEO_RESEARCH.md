# 動画づくりのリサーチと検証(この環境: CPU 4コア・メモリ15GB・GPUなし・空き容量2.5GB)

検証日: 2026-10-12。「確認済み」はこの環境で実際に動かした結果。

## 結論(おすすめ順)
1. **ffmpeg + Python で作る「動く静止画」ショート動画(確認済み・無料・オフライン)**
   - 画像に、ゆれる動き・背景のキラキラ・吹き出しのセリフ・アニメ声・BGM を重ねる。
   - 試作 `scripts/video_proto.py`: 1080×1920・10秒・30fps・音声つきの H.264 動画を、**22秒**で作れた(`output/proto_03_B.mp4`)。
   - 弱い点(直せる): ①吹き出しが顔にかかる配置 ②キラキラが弱い ③512×768 の画像を 1080×1920 に拡大するのでやわらかい ④口は動かない。
2. 口パク・まばたきの追加(部分修正が必要。ユーザーの許可が出てから)。または声の大きさに合わせて体をゆらす(許可不要・確認はこれから)。
3. AI 動画モデル(任意の実験。ネット許可が必要): AnimateDiff を小さく試す。
4. VOICEVOX(アニメ声の本格版): GitHub のリリースの取得が必要(許可が必要)。

## 検証結果の一覧
| 候補 | 結果 | 理由 |
|---|---|---|
| ffmpeg(zoompan・xfade・drawtext・subtitles・overlay・rubberband・minterpolate) | 使える(確認済み) | エンコーダ libx264/x265/vp9/aac あり。日本語フォント IPAゴシック あり |
| Python(numpy)でコマ生成 → ffmpeg に流し込む | 使える(確認済み) | 10秒の動画で22秒 |
| pyopenjtalk(日本語読み上げ、声の高さ・速さ) | 使える(確認済み) | オフライン。アニメ版の声設定は characters.json |
| pip・npm | 使える(確認済み) | moviepy、opencv-python-headless の取得を確認。Remotion(npm)も取得は可能だが未検証 |
| GitHub(github.com の画面・API・リリースのファイル) | ほぼ使えない | 画面400・API403・リリース403。`git ls-remote`(読み取り)と raw.githubusercontent.com は通る |
| Hugging Face(モデル取得) | 許可を外してあるので不可 | 再度の許可が必要 |
| Talking Head Anime 3(1枚のアニメ絵から口パク・まばたき) | 使えない | NVIDIA の GPU(CUDA)が必須。モデルは Dropbox(取得不可) |
| SVD / Wan2.1 / LTX-Video(画像→動画のAI) | 実用外 | 調べた情報では 16GB 以上の GPU メモリ向け。CPUでの速度の資料はなく、未検証 |

| VOICEVOX core(アニメ声の読み上げ) | 未検証 | Python 版は PyPI に無く、GitHub のリリースにある(403)。ソフトは MIT、声(キャラクター)ごとに利用規約あり |
| MoneyPrinterTurbo(全自動ショート動画) | 向かない | LLM のAPIとストック動画(Pexels)に通信が必要。日本語対応は確認できなかった |
| Wav2Lip 系(`lipsync`)、LiteAvatar | 未検証 | 実写向け/アニメ向きは不明。モデル取得の許可が必要 |
| 拡大(アップスケール) | ffmpeg の lanczos で代用中 | OpenCV dnn_superres のモデルは raw.githubusercontent.com から取れる見込み(未検証) |

## 試作の中身(scripts/video_proto.py)
1. 画像を縦いっぱいに拡大して、9:16 に左右を切る。
2. 画像のふちとつながった純黒を「背景」として見つけ、背景だけを動かす(人物の画素は変えない)。
3. 人物は、ゆっくり上下にゆれる(±7画素・3秒周期)。背景の星はまたたく。
4. 声(アニメ版)を 0.9 秒後に入れ、吹き出しのセリフを 1〜9 秒に重ね、BGM を足す。
5. 純黒の背景がある絵だけ、背景だけを動かせる。ほかの絵は全体に重ねる効果(粒・光)だけを使う。
