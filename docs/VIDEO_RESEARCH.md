# 動画づくりのリサーチと検証(この環境: CPU 4コア・メモリ15GB・GPUなし・空き容量2.5GB)

検証日: 2026-10-12。「確認済み」はこの環境で実際に動かした結果。

## 結論(おすすめ順)
1. **ffmpeg + Python で作る「動く静止画」ショート動画(確認済み・無料・オフライン)**
   - 画像に、ゆれる動き・背景のキラキラ・吹き出しのセリフ・アニメ声・BGM を重ねる。
   - 試作 `scripts/video_proto.py`: 1080×1920・10秒・30fps・音声つきの H.264 動画を、**22秒**で作れた(`output/proto_03_B.mp4`)。
   - 弱い点(直せる): ①吹き出しが顔にかかる配置 ②キラキラが弱い ③512×768 の画像を 1080×1920 に拡大するのでやわらかい ④口は動かない。
2. 口パク・まばたきの追加(部分修正が必要。ユーザーの許可が出てから)。または声の大きさに合わせて体をゆらす(許可不要・確認はこれから)。
3. AI 動画モデル(任意の実験。ネット許可が必要): AnimateDiff を小さく試す。
4. VOICEVOX(アニメ声の本格版): GitHub のリリースの取得が必要(許可が必要)。

## 試作の中身(scripts/video_proto.py)
1. 画像を縦いっぱいに拡大して、9:16 に左右を切る。
2. 画像のふちとつながった純黒を「背景」として見つけ、背景だけを動かす(人物の画素は変えない)。
3. 人物は、ゆっくり上下にゆれる(±7画素・3秒周期)。背景の星はまたたく。
4. 声(アニメ版)を 0.9 秒後に入れ、吹き出しのセリフを 1〜9 秒に重ね、BGM を足す。
5. 純黒の背景がある絵だけ、背景だけを動かせる。ほかの絵は全体に重ねる効果(粒・光)だけを使う。

## 追加の検証結果(2026-10-12 午後)
### AnimateDiff(この環境・CPUだけ): 使えない(確認済み)
- 16コマ・384×576: メモリ不足で強制終了(約14GB)。
- 8コマ・320×480(1秒分): 生成189秒で成功。ただし**絵が崩れた**(色が派手に荒れ、輪郭が汚れ、服の形も変わった)。LCM の少ない手順数と、解像度の低さが原因。10秒の動画は約30分かかる計算で、品質も不足。→ 採用しない。
- 使ったスクリプト: `scripts/animatediff_test.py`(検証用)。モデル `guoyww/animatediff-motion-adapter-v1-5-3` を取得した(約0.9GB)。

### Colab(無料GPU)の Stable Video Diffusion: 使える(ユーザーが実行して確認)
- ユーザーが `colab/image_to_video_svd.ipynb` を実行して作った `clip_smooth.mp4`(1024×576・28fps・3.3秒)を受け取った。
- 髪・服が実際に動き、絵の崩れも少ない。隣のコマとの差が大きく、動きは十分。
- 注意: 横長(1024×576)で出た。縦動画にするときは、ぼかした背景を敷いて縦に収める(`scripts/compose_video.py`)。人物は小さくなる。
- 仕上げ: `python scripts/compose_video.py クリップ.mp4 03 B 出力.mp4`(声・吹き出し・BGM・ブーメランで2倍の長さ)。完成例: `output/video_03_B_v1.mp4`(6.6秒)。

### 現時点のおすすめ
1. Colab で縦長(576×1024)のクリップを作る → `compose_video.py` で仕上げる。
2. 長い動画は、複数のクリップ(別の seed や、別の動き)をつなぐ。
3. 口パクは未対応(部分修正が必要。許可があるときだけ)。

### SVD のクリップの正直な評価(ユーザーの指摘「揺れているだけでは?」への確認)
- 測定: コマ間のずれは、全体が右に約12画素/3コマ動く(カメラが動くような動き)のみ。平行移動でそろえても差が残る(19〜23)のは、髪や服の局所の変化ぶん。
- 見た目: 人物は動作(手を振る、話す、振り向くなど)をしていない。髪・服・背景がゆらぐだけ。SVD は動きの指示文が使えないため、動作は指定できない。
- 次の候補: CogVideoX-5B-I2V(画像 + 英語の指示文で動きを指定できる)。Colab の無料GPUで動く資料はある(量子化・メモリ節約が前提)が、未検証。`colab/image_to_video_cogvideox.ipynb` を用意した。
- 口パクは、どのAIでも正確にはできない。実写向けの口パクAI(Wav2Lip系)はアニメに向かない可能性が高い。
